# Butter Bunny POS · บัตเตอร์บันนี่

ระบบขายหน้าร้านสำหรับคาเฟ่และเบเกอรี่ ทั้งระบบอยู่ในไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งหรือ build

## ฟีเจอร์

- **ขายหน้าร้าน:** เมนูมีรูป ค้นหาและกรองตามหมวด เลือกร้อน/เย็น/ปั่นและระดับความหวานได้ เลือกทานที่ร้านหรือกลับบ้าน ออกเลขคิวอัตโนมัติ ใส่หมายเหตุและส่วนลดพิเศษได้
- **ชำระเงิน:** เงินสด (คำนวณเงินทอน), QR พร้อมเพย์ตามมาตรฐาน EMVCo พร้อมยอดเงิน, บัตร (บันทึกเลขอนุมัติจากเครื่อง EDC)
- **ใบเสร็จ:** ใบกำกับภาษีอย่างย่อพร้อม VAT 7% ดาวน์โหลดเป็น PDF ขนาด 80 มม.ได้
- **ออเดอร์:** บอร์ดคิว กำลังทำ → พร้อมเสิร์ฟ → เสร็จแล้ว ยกเลิกบิลพร้อมคืนสต็อก คืนแต้ม และคืนของรางวัลเข้าตู้
- **เมนูและสต็อก:** เพิ่ม/ดู/แก้ไข/ลบเมนูได้ อัปโหลดรูป ตั้งตัวเลือกพร้อมราคาบวกเพิ่ม เติมสต็อก และแจ้งเตือนเมื่อใกล้หมด
- **โปรโมชั่น:** ลด %, ลดบาทต่อชิ้น, ซื้อ X แถม Y, ยอดครบลด กำหนดวัน ช่วงเวลา (Happy Hour) วันเริ่ม–สิ้นสุด และโค้ดคูปองได้ ระบบเลือกโปรที่คุ้มที่สุดให้อัตโนมัติ
- **สมาชิก:** ค้นด้วยเบอร์โทร ได้ 1 แต้มทุก 25 บาท (ตั้งค่าได้) มี 3 ระดับ: ลูกกระต่าย → กระต่ายเนย (ยอดสะสม 2,000 บาท) → กระต่ายทอง (ยอดสะสม 8,000 บาท)
- **ตู้ของรางวัล:** แลกแต้มเป็นเมนูฟรี ของที่ระลึก หรือคูปองส่วนลด แลกได้ทั้งในบิลขายและที่เคาน์เตอร์ ยกเลิกการแลกได้ และมีประวัติการแลกรายวัน
- **รายงาน:** วันนี้ / เมื่อวาน / 7 วัน / เดือนนี้ / กำหนดเอง ดาวน์โหลด PDF ขนาด A4 และ CSV ได้
- **พนักงาน:** เข้ากะด้วย PIN 4 หลัก มีตำแหน่งผู้จัดการและแคชเชียร์ ล็อกหน้าจอเองเมื่อไม่ใช้งาน 20 นาที

## วิธีใช้งาน

ระบบทำงานได้ 2 โหมด และเลือกโหมดให้เองตามที่ที่เปิดหน้าเว็บ

| โหมด | เปิดที่ไหน | ข้อมูลเก็บที่ไหน |
|---|---|---|
| ซิงก์ทุกเครื่อง | เปิดเป็น Artifact บน claude.ai | ฐานข้อมูลกลางของ Artifact ทุกเครื่องเห็นข้อมูลเดียวกันแบบสด |
| ออฟไลน์ | เปิด `index.html` ในเบราว์เซอร์ตรง ๆ | `localStorage` ของเบราว์เซอร์นั้นเท่านั้น |

ในโหมดออฟไลน์ ฟีเจอร์ดาวน์โหลด PDF/CSV และอัปโหลดรูปผ่านที่เก็บไฟล์ของ Artifact จะใช้ไม่ได้ ระบบจะเก็บรูปเป็น data URL แทน

ทดลองในเครื่อง:

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ครั้งแรกระบบจะให้สร้างบัญชีผู้จัดการ (ชื่อ + PIN)

## โครงสร้างไฟล์

```
index.html                  ระบบ POS ทั้งหมด (HTML + CSS + JS)
assets/illustrations/       รูปวาดเมนู 32 รายการ (m-*.jpg) และของที่ระลึก 3 ชิ้น (g-*.jpg) ขนาด 640×480
tools/illustrations/        สคริปต์ที่วาดรูปด้านบนจาก SVG (Node + Playwright)
seed/starter-data.json      ข้อมูลเริ่มต้นของร้าน: เมนู สต็อก โปรโมชั่น ของรางวัล และข้อมูลร้าน
```

วาดรูปใหม่ (ต้องติดตั้ง Playwright และ Chromium ก่อน):

```bash
node tools/illustrations/gen.js
```

```bash
node tools/illustrations/gen2.js
```

```bash
node tools/illustrations/gen3.js
```

## โครงสร้างข้อมูล

| คอลเลกชัน | เก็บอะไร |
|---|---|
| `menu` | เมนู: ชื่อ หมวด ราคา ตัวเลือก ระดับความหวาน นับสต็อกหรือไม่ รูป |
| `stock` | จำนวนคงเหลือ: `<menuId>` สำหรับเมนู, `rw-<rewardId>` สำหรับของรางวัลที่จำกัดจำนวน |
| `promos` | โปรโมชั่นและเงื่อนไข |
| `rewards` | ของรางวัลในตู้ |
| `members` | สมาชิก ใช้เบอร์โทรเป็น id |
| `staff` | พนักงานและ PIN (เก็บเป็น SHA-256 พร้อม salt) |
| `config/shop` | ข้อมูลร้าน พร้อมเพย์ VAT อัตราแต้ม |
| `days/<YYYY-MM-DD>/orders` | บิลขายแยกตามวัน |
| `days/<YYYY-MM-DD>/redeems` | ประวัติการแลกของรางวัลแยกตามวัน |

`seed/starter-data.json` มีเฉพาะข้อมูลร้าน ไม่มีพนักงาน สมาชิก หรือยอดขาย ในไฟล์นี้ฟิลด์ `imgFile` ชี้ไปที่รูปใน `assets/illustrations/` แทน id รูปของ Artifact

## สิทธิ์การใช้งาน (โหมดซิงก์)

สิทธิ์จริงควบคุมด้วยเมนู Share ของ claude.ai ส่วน PIN มีไว้สลับพนักงานบนเครื่องเดียวกัน

- **Editor:** แก้เมนู โปรโมชั่น ของรางวัล ข้อมูลร้าน และพนักงานได้
- **Contributor:** ขาย บันทึกออเดอร์ ปรับสต็อก จัดการสมาชิก และแลกของรางวัลได้
- **Viewer:** มองไม่เห็นข้อมูลร้าน

## ข้อจำกัด

- ระบบยืนยันการชำระเงินกับธนาคารเองไม่ได้ พนักงานต้องตรวจยอดในแอปธนาคารก่อนกดยืนยัน ส่วนบัตรต้องรูดที่เครื่อง EDC แยกต่างหาก
- หน้าเว็บสั่งพิมพ์โดยตรงไม่ได้ ให้ดาวน์โหลด PDF แล้วสั่งพิมพ์จากไฟล์
- ฐานข้อมูลของ Artifact เก็บได้ราว 25,000 รายการ ถ้าขายวันละ 100 บิลจะเต็มในราว 8 เดือน
- ปุ่มยกเลิกในประวัติการแลกของรางวัลแสดงเฉพาะการแลกของวันนี้
